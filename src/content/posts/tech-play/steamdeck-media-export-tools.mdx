国庆休假了一周（其实也写了些星际拓荒游记，只是还没写完就一直没上传），下一周又开始缓慢头疼，今天也头疼，不过这几天Vibe Coding做了点东西，介绍一下

## 起源

我长期用SteamDeck玩游戏，便携、性能大部分时候也够用。但是打游戏难免有想记录下来的片段，在手机上或电脑上发给朋友、发到B站。Windows有OBS和自带的英伟达快速30秒录屏，Deck如果不在桌面版玩游戏的话，就只能用Steam 2024年出的录制功能。我对所有游戏默认开启1小时录制，然后用快捷键切片45秒下来分享，整个过程很顺畅很舒服，**如果你在国外的话**

Steam录制的视频不是常见的mp4格式，无法直接提取。一分钟内的录屏可以通过「快速分享」的方式下载到手机或电脑上，大于一分钟的视频只能在桌面模式下导出成mp4。快速分享是把你的视频临时上传到Steam上，严重依赖顺畅的网络环境，而总有些时候网络就是很不好，上传一个视频要换一堆节点重试很多次，影响心情。

更别提大于一分钟的“大视频”非得打开桌面模式去导出，导出速度还巨慢无比天知道为什么，测试下50分钟的视频体感至少要15分钟的导出时间，而且和之后我自己Vibe的工具导出的视频体积相当画质也无区别，完全不知道多余的时间消耗来干嘛了

而其他两三分钟的“Steam官方认证大视频”如果使用桌面端导出到本地则没有快速分享那么强大的压缩，一个45s的视频40-80MB发到QQ上不能快速预览，更别提不管用哪种方法导出完了还得自己想办法从SteamDeck上传到手机或电脑上，无论是通过KDE Connect远程连接，还是数据线直连，都距离在Windows电脑上分享视频的便利相差甚远

还有图片分享问题，快速分享只能分享视频，游戏模式下图片的话网络好可以手机发给Steam，Steam接收，但同样看网络稳定性，桌面模式可以打开截图会存一份原版到本机的功能，在需要更高清的图片时很有用(Steam截图自带压缩功能，一张1.2mb左右的图片最后可能不到100kb，但清晰度通常不受损)，但全部图片都堆在一起，没有分类也不好找，而且显然还是需要打开桌面模式

## 尝试解决

关于录制问题，我找过很多解决方法：

- 有一个Decky Recorder的录制插件，录制下载直接是mp4，然而视频体积大，录制过程也并没有Steam自带的那么即开即用，且显然无法利用Steam自带的视频剪辑功能，不提供远程下载视频的方法

- 游戏模式下通过某种手段可以获得一个嵌套桌面，但这个嵌套桌面没有Steam，而且每次打开这个桌面模式我的性能HUD就会莫名消失直到下次重启Deck

- UU加速器给Deck加速，如果用了其他科学工具可能会有冲突，而且也无法解决大于一分钟的视频导出问题

- 一个自称自己可以导出视频、还可以直播的软件Deck Cast，但它最终证明自己没有用，只能导出它预览的那三秒钟

- 一个叫FragMend的Steam软件，是收费的，可以按分类查找一个游戏的后台录像或剪辑，然后导出，功能相对完善，显然是AI写的，卖36块。我抱着尝试的心态下载了一个Demo，点击启动后毫无反应，我以为是坏了正要卸载，发现它在后台静默打开了火狐浏览器？？？打开了一个本地服务器网页？？？你都上架了甚至不舍得做一个套壳吗那不是在游戏模式下没有火狐浏览器你都打不开？是很有用的参考但完全不考虑买

关于图片问题，我也尝试了很多方案：

- 有一个Decky插件叫Shooty，点一下就可以把截图按游戏分类保存到某个文件夹下，一开始这是个好方案，很快就发现了很多问题。首先它似乎不满足于“我点它才存”，有时候我不点它也存了，也不知道后台管理在干什么；其次如果一个游戏有中文名字，例如巫师3狂猎，它会中文名存一份英文名存一份儿，而且这两个的截图进度可能并不同步，会出现一个有某张图一个没有的情况；如果我对非Steam游戏截图，它会使用随机生成的id代替，不好判断是什么游戏。不过如果你不介意这些问题，总体来说是可用的，只是没有比自带的原图存档功能好多少

- 之前有一个国内大佬开发的FriendDeck插件，他也开发了更早的decky-localsend，FD提供图片预览和下载功能，但没有按游戏分类功能，多选下载不算特别好用，不过它支持在手机端下载图片，而且还额外支持在手机端简单的操控文件系统，相对来说很不错了。我曾经试图在他的项目基础上修改成更符合我心意的版本，然而失败了，项目复杂且没有清晰的部署方法

- 由于Steam自带的原图本地保存功能，更“Hack”的方式之一是直接用ssh在电脑端提取图片，FTP工具在手机上预览图片，但我的网络环境有点糟糕，一台更优秀的路由器在客厅但它的信号在房间里很差，一台网络糟糕的路由器通过网线从那台路由器接到我房间里，而路由地址也远非固定，换来换去体验很差

- 更简单的方法，利用插件打开一个远程文件管理器，这样的插件有不少，像DeckyFileServer，但通常都无法预览图片，只能靠悟知道自己要哪张图，通常也不支持多选

综上所述，在我看到FragMend之后，我决定做一个自己的Steam录制和截图软件，方便查看和导出。那个据说自己可以直播的软件和它都给了我很多启发

## 功能介绍

一开始做的时候只打算做一个命令行小工具，但逐渐变成了桌面端和Decky Loader都可以运行的项目，还是没想好叫什么名字，姑且在这里称呼为Steam Media Export（SME?)

::github{repo="coyoteshkw/steamdeck-media-export"}


### 录像处理

利用伟大的ffmpeg，SME可以实现录像的预览、导出和下载到其他设备

网页端大概长这样，不难看但也没什么特色，不过一个小实用工具就不讲究那么多了，很多前端细节我都没修，以后有机会再看

![image.png](https://img.055933.xyz/file/1792397425500_image.png)

所有的录像按不同游戏分类展示，并且会自动抽取游戏封面方便分辨，非Steam游戏也会尽量抽取，例如这是我以前下载的学习版章鱼奶爸(现已入正)。默认按照最近录制的游戏排列，可以改成按体积或游戏名称

![image.png](https://img.055933.xyz/file/1792397821953_image.png)

考虑到会有多个账号的情况，可以在右上角切换不同账户

展开任一游戏折叠框，会展示全部剪辑和后台录像等，一开始考虑再做一个分级分开展示，后来感觉没必要，剪辑的数量最后总是会远大于后台录像和手动录制的，这就是Steam录制在Deck上最重要的功能，如果你有高清录制需求一开始就不应该选择在Deck上玩，毕竟大部分游戏720P运行。这里展示我的星际拓荒各种剪辑

![image.png](https://img.055933.xyz/file/1792397398964_image.png)

点击封面会渲染一个低分辨率5s静音片段，从视频中段抽取(考虑到录制中切片是一个倒序发展的情况，片段开头是什么很不可控)，方便以最低成本检查剪辑内容

之后是录制时间(同时也是默认的导出文件名)、视频时长、原文件名

末尾三个按钮

1. 「在线播放」，会打开浮窗，渲染最长五分钟的录像(如果超过五分钟我觉得不如就下载下来看吧，为什么要在线看)，适合在5s片段无法判断内容时快速检查，视频是实时渲染和传输的，不本地保存，不占存储空间

:::image-figure[在线播放页浮窗]
![image.png](https://img.055933.xyz/file/1792399276360_image.png)
:::

2. 「下载到本机」，SME支持远程打开网页管理端，手机端的网页响应式也做好了。可以随时下载片段到手机上。为了支持进度显示和断点续传，会先在Deck本地转码为mp4再传输，转存内容最多缓存5GB，可以自己清理。为了方便，下载到本机支持特定压缩，可以像Steam的快速分享那样把视频大小压缩到10mb左右

:::image-figure[本机导出选项]
![image.png](https://img.055933.xyz/file/1792400178935_image.png)
:::

3. 「删除」，加起来我也录制了60个G的视频了，有些录像上传到B站了就可以删了。支持先放到回收站或彻底删除

### 录像导出(到Deck)

导出到Deck默认为无损导出，速度嘎嘎快谁用谁知道，实测50分钟的星际拓荒结局只要不到几分钟，45s小视频那就是一瞬间的事情

支持多选，你可以直接选一个游戏的所有剪辑一键导出，部分视频如果导出视频会自动跳过。偶尔会出现SteamDeck录制出错的情况，软件会先尝试修复录像，修复不了再跳过，我用它修复了我第一次玩动物井的视频

支持导出预演，假如你的Deck内存不是很大的话可能会需要这个，可以告诉你导出大概会有多大

![image.png](https://img.055933.xyz/file/1792400788822_image.png)

也支持压缩转码，但是会比较慢，虽然比Steam自带的导出可能快点。推荐没有特殊需求就无损导出，分享到QQ群等私人空间就用下载到本机。

> 注意：在手机端也可以操作来导出到Deck

### 截图处理

一开始没打算做，但后来一想录制都做了那截图一块儿做了得了

功能模仿原版，默认展示全部截图的缩略图(提取了默认的缩略图，在大屏幕上看可能显得很糊)，点击进去才加载原图。不过这个原图是Steam已经压缩过一道的，不大。如果想要完全没压缩过的只能在Steam设置里保存一份原图到本地文件夹了，通常来说区别不大，看起来都很清晰，神秘Steam压缩面包

没有封面的非Steam游戏默认读取其第一张截图作为封面，通常来说够用了

## 使用方式

### 游戏模式

我打包了一份Decky插件，下载后在Decky中安装本地zip即可。使用很简单，开启服务会展示本地可连接的地址，也提供二维码方便手机扫描来打开手机端进行操作

![image.png](https://img.055933.xyz/file/1792487802861_image.png)


### 桌面模式

目前可以通过命令行来启动

```sh
# steam-recording-exporter/
./bin/steamexport serve --host 0.0.0.0 --token 'hello'
```

如果不想输长命令，可以用这个

```bash
./bin/steamexport-serve
```

这条命令可以安装一个桌面快捷方式，方便启动。主要是SteamDeck桌面模式下键盘没有Ctrl键，终端程序启停很不方便

```bash
./bin/install-desktop-shortcut.sh
```

其他命令行具体使用方法可以查看README文件，也可以丢给AI让AI给你分析
